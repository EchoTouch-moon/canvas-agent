# Canvas Agent 设计文档包

**版本：Design Baseline v1.1**  
**整理日期：2026 年 8 月 6 日**

本目录将六份阶段性材料与后续对话中已经确认的设计决定，整理为一套可直接服务于 MVP 原型开发的文档基线。v1.1 新增已经确认的 UI 设计与开发基线。

## 使用方式

- 日常了解项目全貌：阅读《Canvas Agent 项目总设计基线 v1.0》；
- 设计数据库与领域对象：阅读《核心领域模型与业务规则》；
- 开发 Context Composer 或 Worker：阅读《上下文与执行架构》；
- 设计页面与交互：阅读《产品形态与核心用户流程》；
- 安排开发顺序：阅读《MVP 开发范围与实施路线》；
- 查询某项决定为什么这样定：阅读《架构决策记录 ADR》；
- 避免过早设计：阅读《延期设计与待验证问题》；
- 统一命名：阅读《术语表》；
- 开发页面与组件：阅读《UI 设计与开发基线》。

## 状态标记

- **CONFIRMED**：已经在讨论中明确确认，后续实现默认遵守；
- **MVP**：第一版需要实现或验证；
- **PROVISIONAL**：当前建议，可由技术原型调整；
- **DEFERRED**：明确延期到开发对应阶段再设计；
- **OUT OF SCOPE**：当前 MVP 不实现。
