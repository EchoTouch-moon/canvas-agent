# Canvas Agent 术语表

| 术语 | 固定含义 |
|---|---|
| Project | 被系统长期管理的一个软件项目边界 |
| Node | 长期稳定、可独立引用的项目语义身份 |
| NodeDraft | Node 当前可变工作稿 |
| NodeVersion | Node 某一时刻的不可变正式内容 |
| Edge | 两个 Node 之间的长期语义关系 |
| SavedView | Canvas 或其他视图的坐标、过滤和展示配置 |
| ProjectBaseline | 某阶段正式确认的项目事实、关系与可选代码版本集合 |
| Task | 具有明确目标、范围和验收条件的工作单元 |
| TaskDraft | 尚未确认的任务工作稿 |
| TaskSpecVersion | 一次不可变任务定义 |
| TaskTarget | Task 计划改变或验证的 Node / NodeVersion |
| AcceptanceCriterion | 判断 Task 是否达到目标的结果条件 |
| AcceptanceEvaluation | 某次 Run 对验收条件的验证结果 |
| TaskDependency | 两个具体 Task 之间的执行计划依赖 |
| ContextSnapshot | 某次 Run 启动时的模型无关冻结初始上下文 |
| ContextSnapshotItem | Snapshot 中一个冻结内容项目 |
| ContentBlob | 按内容 Hash 存储的实际内容副本 |
| RepositoryRevision | Commit 与工作区 Diff 共同构成的代码事实状态 |
| Run | 完成某个 TaskSpecVersion 的一次真实执行尝试 |
| Run status | Run 当前生命周期阶段 |
| Run outcome | FINISHED Run 的最终执行结果 |
| ExecutionRequest | 调度器交给 Worker 的不可变执行合同 |
| Worker Attempt | Worker 对某个 ExecutionRequest 的一次领取和执行片段 |
| Worker Capability | Worker 环境具备的能力 |
| ToolPolicy | 本次 ExecutionRequest 被允许使用的工具和参数边界 |
| RunEvent | Run 期间的追加式事件记录，详细协议延期 |
| ToolInvocation | Run 中一次工具调用，详细协议延期 |
| Checkpoint | Run 可恢复位置及必要外部状态，详细协议延期 |
| Artifact | Run 产生的正式结果，生命周期详细规则延期 |
| Approval | 对精确高风险动作或正式状态转换的授权 |
| Input Request | Agent 在 Run 中向用户请求普通信息或选择 |
| Context Composer | 选择、分析、预览并冻结 Snapshot 的界面 |
| Canvas Map | 以局部图方式探索项目语义关系的高级视图 |
| Active Baseline | Project 当前唯一正式生效的 Baseline |
| CURRENT Snapshot | 与当前基线、任务和代码仍一致的 Snapshot |
| STALE Snapshot | 可复现但已有更新状态的 Snapshot |
| DIVERGED Snapshot | 与当前项目或代码实质偏离，不适合直接重用的 Snapshot |
