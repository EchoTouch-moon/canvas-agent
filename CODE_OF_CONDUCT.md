# Code of Conduct

Canvas Agent is a collaborative project. We want participation to be safe, respectful and useful for people with different backgrounds and levels of experience.

## Expected behavior

- Be respectful, constructive and specific.
- Assume good intent while discussing evidence and design trade-offs.
- Focus criticism on code, documentation and decisions, not on people.
- Respect project scope, ownership boundaries and maintainer decisions.
- Protect private information and do not publish credentials or personal data.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disruption, doxxing, unwanted sexual attention, and publishing someone else's private information are not acceptable.

## Reporting

Please report conduct concerns privately to the repository maintainers through their GitHub profile rather than opening a public issue. Security vulnerabilities should follow [`SECURITY.md`](SECURITY.md). Maintainers may remove comments, close discussions or restrict participation when necessary to keep the project safe and productive.
