# Scope register

## Core — current MVP

- Project / Node / Edge / Baseline facts
- Task / TaskSpecVersion / AcceptanceCriterion
- Context Composer and immutable ContextSnapshot
- one local Worker, isolated Git worktree, Diff/Test/Summary artifacts
- Artifact review, Task completion and Baseline Draft
- MUSICDB 0 → 1 → 1.1 validation
- compact desktop UI foundation with accessible light/dark semantics

## Enhancements — candidate after core loop evidence

- richer Inspector panels and keyboard command coverage
- advanced tables and comparisons
- fuller Run event presentation using the observed event set
- local one-hop relationship mini-map

These improve speed or understanding but do not prove the core execution loop.

## Future directions — require explicit trigger

- real Checkpoint recovery (trigger: first recoverable Worker interruption data)
- second Agent adapter (trigger: first adapter stable and contract gaps measured)
- local Canvas/SavedView expansion (trigger: core flow stable and impact-analysis need observed)
- multi-user permissions (trigger: verified team demand)

## Idea repository — not scheduled

- global infinite Canvas
- distributed Worker fleet
- autonomous multi-Agent negotiation
- full-repository vectorization and automatic context optimization
- enterprise billing and audit administration

These conflict with the current goal of validating a low-maintenance local-first core loop.
